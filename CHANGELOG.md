# Changelog

All notable changes to Fantasy Mouse UI are documented here.

## [Unreleased]

### Added

- A capability-bounded Agent usage guide with two copy-ready Chinese prompts for installing-and-using or invoking an existing Fantasy Mouse UI installation.
- A roadmap that separates proposed v0.2.1 and v0.3.0 work from behavior shipped in v0.2.0.

### Changed

- The README Quick Start and live v0.2.0 Release body now link to the complete Agent guide without changing the version-pinned tag or release ZIP.

## [0.2.0] - 2026-09-07

### Added

- Fast, Standard, and Strict execution profiles with automatic Strict upgrades for high-risk and formal work.
- Four accepted Strict benchmark cases covering a SaaS dashboard, website, presentation, and Windows desktop application.
- A result-led README, concise Quick Start, three bilingual example prompts, and a deterministic 22-second Archive Lantern workflow demonstration.
- A public `examples/` evidence contract with editable source, real output, screenshots, comparisons, accessibility checks, and independent acceptance gates.
- `ASSET_PROVENANCE.md` and package notices that separate MIT software-code licensing from the unverified origin and unconfirmed rights status of bundled imagery.

### Changed

- Expanded the deterministic plugin archive from the historical 20-entry v0.1.0 inventory to the exact 24-file v0.2.0 inventory.
- Hardened benchmark and package tests for path escape, reparse points, hard links, races, file identity, PNG validity, and source/output parity.

## [0.1.0] - 2026-08-28

- Initial public release with the canonical Fantasy Mouse identity, action-hand authority, product-style independence, host adapters, and deterministic packaging.
