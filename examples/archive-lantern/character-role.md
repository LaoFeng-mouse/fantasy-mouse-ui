# Archive Lantern character-role translation

This table derives character participation only from the canonical identity and Archive Lantern's workflow meaning. It does not define layout, palette, typography, materials, components, or character placement.

Stable in every shown state: compact round grey texture-rich head, tiny horizontal ears, narrowed vacant eyes, prominent human-like toothy grin, compact white hand-drawn bean body, recognizable proportions, and earnest absurd dreamer temperament.

| Workflow state | User truth | Role | Clothes | Props | Pose and expression | Hand mode and real contact | Background | Bubble |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `empty-library` | No items are indexed; importing is the next available action. | Waiting librarian | Simple librarian waistcoat or badge | Empty catalog tray beside the real Import control | Calm, welcoming, restrained expression; body leaves the control unobscured | Default clasped mode: the chest V/U is the only hand pair; no action hands | Quiet empty shelf cue only if it helps explain the state | None; the real empty-state heading and instructions carry meaning |

| `no-results` | The query has no matches and focus can return to search for recovery. | Search guide | Same librarian attire | Search card near the real Clear or Search control | Restrained, helpful expression | Action mode only if the character is shown: remove the chest V/U and use one pair touching the real Clear or Search control; otherwise omit the character | None | None |

The character is required only in `empty-library`, `indexing`, and recovery (`import-failed`) states. It is omitted from ordinary indexed, tagging, search-results, and open-result work so the archive content remains primary. Any action pose must show one coherent pair of forearms and hands attached below the head/body seam, with correct occlusion and no chest V/U.
