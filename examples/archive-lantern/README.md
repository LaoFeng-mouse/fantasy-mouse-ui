# Archive Lantern

Archive Lantern is the strict desktop benchmark case for a PowerShell 7 and WPF personal-library application. This directory currently contains only the pre-implementation brief, mode decision, character translation, product-style derivation, and pending QA record.

The required primary journey is:

`empty-library -> import -> indexing -> indexed -> tag -> search -> open-result`

The eventual implementation must also exercise a failed import, retry recovery, duplicate handling, keyboard navigation, visible focus, status announcements, and a recoverable no-results path. The mouse participates as a librarian only in the empty-library, indexing, and recovery states. In action states, its single action-hand pair must replace the default chest V/U and touch the real import, indexing, or retry control.

No source, runnable output, screenshots, or comparison artifact exists yet. Every evidence gate remains false and every status remains pending.
