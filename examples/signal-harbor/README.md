# Signal Harbor

Signal Harbor is the accepted Strict benchmark case for a dense incident-monitoring SaaS dashboard. Its verified journey is:

`monitoring -> incident-selected -> assigning -> assigned -> resolving -> resolved`

The real-browser run covers blocked assignment, failed resolution, retry, deterministic post-action focus, arrow-key queue navigation, polite live-region announcements, measured text contrast, and reduced-motion behavior.

The mouse participates as an `incident-dispatcher`. Default, resting, and recovery appearances retain the chest V/U as the sole clasped hand pair. Action mode is permitted only during `assigning` and `resolving`; it replaces the chest V/U with exactly one coherent action-hand pair. Other states must not imply action anatomy.

## Result

The standalone source and mirrored output are implemented without runtime dependencies. Seven 1440 by 900 screenshots record monitoring, selection, both action states, both recovery states, and resolution. `evidence/comparison.png` places the canonical identity, action-hand authority, selected composition reference, and rendered product in one review context. The QA record is accepted only after the complete browser journey and repairs were rerun.

The public benchmark trigger upgrades the requested Standard mode to Strict.
